📘 How to Setup Free Gmail App Password (Step-by-Step for Store Owners)

  1. Go to your Google Account Security: myaccount.google.com/security
  2. Ensure 2-Step Verification is switched ON.
  3. Open App Passwords (myaccount.google.com/apppasswords).
  4. Type "Scented Bubbles" as the app name and click Create.
  5. Copy the 16-letter code and paste it into the SMTP Password field below.
